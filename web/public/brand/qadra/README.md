# Recursos gráficos de Qadra

Origen: [eddndev-archive/qadra](https://github.com/eddndev-archive/qadra),
revisión `cdcc2859c71afb71f2edead284e971ca8a333d16`.
Importados el 12 de septiembre de 2026.

Estos archivos conservan los bytes de los originales:

| Archivo local | Ruta original | Uso en esta interfaz |
| --- | --- | --- |
| `logo.svg` | `public/img/logo.svg` | Símbolo de acceso y navegación |
| `favicon.svg` | `public/favicon.svg` | Ícono de la pestaña |
| `logo.png` | `public/logo.png` | Ícono PNG de respaldo |
| `LICENSE.txt` | `LICENSE` | Texto de licencia del repositorio de origen |

El SVG comparte los tres trazos con el componente
`resources/views/components/application-logo.blade.php` del origen. La
interfaz aplica un filtro CSS blanco sobre fondos oscuros para reproducir la
presentación de ese componente, sin alterar la geometría ni el archivo.
El tono verde azulado del SVG original no sustituye la paleta azul del producto.

El archivo de licencia original contiene GNU GPL versión 3, y los manifiestos
del origen declaran `GPL-3.0-or-later`. Su README menciona MIT de forma
contradictoria; aquí se conserva el texto de licencia recibido sin cambiarlo.
Los SVG no contienen avisos adicionales de autoría. La marca procede del
equipo de Qadra.
